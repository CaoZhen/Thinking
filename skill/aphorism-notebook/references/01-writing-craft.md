# 写作技巧：箴言与旅程

这套笔记的写作标准只有一条总纲：

> **箴言要被记住，旅程要被相信。**

箴言靠骨头（结构），旅程靠血肉（细节）。

---

## 一、箴言的解剖

好箴言 = **一个具体的意象** × **一次转折**。

- 意象：可以被看见的名词（钥匙、电梯、账单、雨、代码、粥）。
- 转折：读者预判的方向被轻轻拧了一下。

如果一句话里只有抽象名词，它一定失败。如果一句话里没有转折，它只是一句陈述。

**四种可靠骨架**

| 骨架 | 形状 | 例（原创，可直接作参考语气） |
| --- | --- | --- |
| 反常识断言 | 把公认的说法反过来，但要站得住 | 「删除比添加更需要勇气」 |
| 意象 → 落点 | 前半句具体，后半句抬升 | 「雨不解释它为什么下」 |
| 对偶反转 | 两个对称结构，后半句变向 | 「把问题变小，而不是把人变大」 |
| 第二人称诘问 | 直接对读者说话，不给答案 | 「你上一次不被打扰，是几点？」 |
| 数字骨架 | 用一个具体数字承担全部重量 | 「三十七度的手，先凉的那一寸」 |

**长度感知**（中文）

| 字数 | 感觉 |
| --- | --- |
| 4–7 | 太短，往往成了口号或成语 |
| **8–14** | **最佳区：能容纳意象 + 转折** |
| 15–18 | 边缘，需要朗读确认不喘 |
| > 22 | 失败：已经是句子，不是箴言 |

---

## 二、删字练习（写完必做）

压缩是删，不是造。把 40 字的初稿压到 12 字，留下最硬的那个词。

| 初稿（40±） | 删后（10±） | 删掉了什么 |
| --- | --- | --- |
| 我们常常为了逃避一个困难的问题，而去做很多简单的事，最后看起来很忙 | 「忙碌是恐惧的伪装」 | 主语、解释、"看起来很" |
| 时间并不会真的治愈一个人，它只是让人习惯了伤口的样子 | 「治愈是伤口学会了风景」 | "并不会真的""只是"、第二人称 |
| 城市里的孤独不是因为人少，而是因为没有人愿意先开口 | 「城市不缺人，缺先开口的人」 | "孤独""因为""愿意" |

**删除清单**：其实 / 总是 / 真的 / 非常 / 十分 / 在我看来 / 我觉得 / 我们应该 / 这个时代 / 众所周知。
**替换清单**：形容词 → 动词或数字；抽象名词 → 具体物件；被动 → 主动。

---

## 三、让箴言带上"社会意识的回音"

私人感受会让读者走开，时代感会让读者停下。三步：

1. **找到"我们"**：这句话说的是"我"，还是"我们都在做的事"？把它从"我"推到"我们"（例：我把注意力卖给了谁 → 我们的注意力被谁定价）。
2. **找到代价**：每一个便利背后都有账。指出账单，而不是指责对方。
3. **找到替身**：把抽象的社会角色换成一个具体的替身（不是"劳动者"，是"在雨里等了 47 秒的外卖员"）。

**不要**：把回音写成"批判"或"控诉"。这套笔记的目标是让读者看见结构，不是让读者生气。

---

## 四、旅程的写法

三段式不是格式，是**注意力路线**：

```
## 起 —— 具体到不需要形容词
## 转 —— 一次追问（可以走偏，但要有脚印）
## 落 —— 把答案换成一个更好的问题
```

### 细节是唯一的信用

抽象句子与抽象句子连在一起，读者会怀疑你在骗他。至少写进一个**只有当事人才知道的细节**：时间戳、原话、数字、屏幕上的光、某人的口头禅。

- 弱：「那天我很累。」
- 强：「凌晨两点十七分，我第一次希望那个 bug 留在原地。」

### 节奏

- 长句之后必须跟一个短句。短句是锤子。
- 一段只推进一步。段落超过 5 行就要检查是否塞了两件事。
- 允许一个破折号、一个括号里的自嘲，但整篇不要超过两处。

### 结尾的三种技法

1. **把答案换成一个更好的问题**（最常用）。
2. **克制的承认**：不解决，只承认真相（「那天晚上我没有找到答案，但我把问题放回了它该在的地方」）。
3. **一个动作**：用一个小动作收束（「我把那盏灯留着没关」）。

**禁止的结尾**：升华式口号、引用名人名言、"让我们一起……"。

---

## 五、情绪的用法

- **克制比宣泄动人**：不要写"痛苦"，写"我把那句气话删了三次"。
- **不解释自己的感动**：让画面自己生效，读者不需要你标注哪里该感动。
- **允许自我怀疑**：一段真实的迟疑比一段坚定的结论可信十倍。
- **不要自怜**：自怜会瞬间把思想变成抱怨。

## 六、完整正例（语气参照，非模板）

> **箴言**：算法比我更早知道我想要什么
>
> **起点**：深夜点开购物软件，首页正好是我下午想过的那双鞋。

```
## 我什么都没搜索

下午三点，我在电梯里想到一双鞋，没搜，没说，也没点开任何商品页面。
晚上十一点，首页第一件就是它。

## 谁替我的欲望做了准备

它没有读我的心。它读的是我停留过的那零点七秒、是我滑过同类内容时多留的那一格屏幕。
我的犹豫被记录成数据，又被还原成一句"你也许喜欢"。
我以为是自己在选择，其实我在确认。

## 还是想要

我没有关掉推荐，我下单了。
只是从那天起，我开始想知道：那双鞋是我想要的，还是我被安排着想要的。
这两件事的差别，可能就是我剩下的一点点自由。
```

好在哪里：有数字（零点七秒）、有具体动作（没搜、没说）、有自我驳斥（我还是下单了）、结尾是问题而不是答案、没有一句批判式的愤怒。

## 七、完整反例

```
## 人生感悟

人生就像一场旅行，我们要学会珍惜当下，不要总是抱怨，
要积极地面对生活，因为每个人的时间都是有限的。
在这个快节奏的社会里，我们更应该放慢脚步，感受生活的美好。
```

问题：① 全是抽象名词与成语；② 说教（"我们更应该"）；③ 没有出处、没有细节；④ 任何一天任何平台都能发；⑤ 读者读完不会停半秒。**这类文字一律不写。**

---

## 八、语感训练（写完的最后一遍）

1. **读出声**。读到打结的地方就是要删的地方。
2. **删掉所有副词**，看你是否还心疼；如果不心疼，原本就是虚的。
3. **换掉第一个动词**。写下第一个动词，想一个更准的替代（走 → 蹭、挪、绕）。
4. **换主语**。把"我"换成"我们"再读一遍，看它是私人牢骚还是共同的处境。
5. **隔夜再看**。第二天读，如果它能让你自己停半秒，它可以发；如果只是觉得自己写得不错，删掉重写。
