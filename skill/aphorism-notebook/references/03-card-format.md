# 卡片格式规范

一张卡片 = 一个 Markdown 文件，放在 `content/cards/<slug>.md`。**文件名就是地址**。

---

## 一、Front matter 字段

```markdown
---
title: 删除比添加更需要勇气      # 必填，箴言正文（单行）
date: 2026-10-11                 # 必填，YYYY-MM-DD
mode: 会话回望                   # 建议填，见下表
tags: [克制, 手艺]               # 建议填，≤ 3 个
place: 深夜的编辑器              # 可选，场景，会显示在卡片上
seed: 一次重构里删掉 400 行之后  # 建议填，"起点"，一句话说明什么触发了它
quote: 删掉之后，代码自己安静了   # 可选，题记，会渲染成引文块
pinned: false                    # 可选，保留字段
---
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `title` | ✅ | 箴言。8–16 字最佳，上限 22 字；单行；结尾不加「。」「！」 |
| `date` | ✅ | 首次写下这张卡的日期，决定排序与"最近更新" |
| `mode` | 建议 | `时事沉思 / 会话回望 / 悬问求索 / 生活即景 / 旧笺重读` |
| `tags` | 建议 | 2–3 个主题词，用于筛选。用中文名词，不要用 `#` |
| `place` | 可选 | 一个具体的场景（"末班地铁""出租屋的窗台"），比"家"更有画面 |
| `seed` | 建议 | 起点：这张卡是被什么触发的。一句话，不解释 |
| `quote` | 可选 | 题记/一句题眼，展示在正文之前 |

**slug 规则**：小写英文与数字，短横线分隔（`^[a-z0-9]+(-[a-z0-9]+)*$`），2–5 个词，能让人猜到意思（`delete-needs-courage`）。

---

## 二、正文约定

- 2–6 个 `##` 小节，每节 1–3 段。
- 首节用具体画面开场；末节收在问题或克制的承认上。
- 支持 `> 引用`、列表、`**强调**`、`[链接](url)`；不支持原始 HTML。
- 小节标题要有画面感：`## 一条 47 秒的新闻` 好过 `## 背景分析`。
- 第一行若写在任何 `##` 之前，会作为「序」呈现。

---

## 三、机器校验规则（`node scripts/validate.mjs --strict`）

| 级别 | 规则 |
| --- | --- |
| 错误 | 缺 `title` / `date` 格式错 / slug 非 kebab-case / title 少于 4 字 / title 超过 22 字 / 正文超过 2000 字 / `##` 小节超过 6 个 / 全文缺少 front-matter / 与已有卡片箴言重复 |
| 提醒 | title 超过 16 字 / title 以句号或叹号结尾 / 正文不足 120 字或超过 900 字 / 小节少于 2 个 / 缺 `mode` / 缺 `tags` 或超过 3 个 / 缺 `seed` / `mode` 不在推荐集合内 |

`--strict` 会把提醒也视为失败，CI 使用的就是它。**处理提醒而不是绕过它**：要么改，要么在提交信息里说明为什么这个提醒不适用。

## 四、完整示例

```markdown
---
title: 名字是代码里最短的注释
date: 2026-10-09
mode: 会话回望
tags: [手艺, 命名]
place: 凌晨的重构
seed: 把 handleClick 改成 confirmRefund 之后，那个函数短了一半
---

## 三个字母的谎

`handle` 这个词用了两年，谁也没觉得不对。
它诚实地说出了自己的无能：它什么都在处理，所以什么都处理不好。

## 改名之后

我把它改成 `confirmRefund`，编辑器里忽然安静了。
原来那个 40 行的函数，有 12 行在处理"万一不是退款呢"——
那些行不是逻辑，是名字太模糊时留下的补丁。

## 名字先于结构

我没有重构，我只改了一个名字，结构自己松开了。
后来我养成一个习惯：看不懂一段代码时，先给它换个名字。
名字对了，多余就会显形。
```

对应校验结果：title 12 字 ✅、正文 ~230 字 ✅、3 个小节 ✅、tags 2 个 ✅ —— 全部通过。

## 五、标签与模式的使用习惯

- 标签是**主题**不是**情绪**：`克制`、`时间`、`注意力`、`手艺`、`城市`；不要 `emoji`、不要 `感悟`、不要 `其他`。
- 同一主题累积到 3 张以上，说明你可以写一张"汇总视角"的卡片（模式 E）。
- 模式分布本身是内容健康度指标：如果连续 5 张都是 `时事沉思`，换 D 或 C，让笔记有呼吸。
